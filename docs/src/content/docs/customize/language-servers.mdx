xtralab includes
[`jupyterlab-lsp`](https://github.com/jupyter-lsp/jupyterlab-lsp), which
gives completions, diagnostics, and code navigation in editors and notebooks.

| Language               | Server                                                                                                   | Installation                     |
| ---------------------- | -------------------------------------------------------------------------------------------------------- | -------------------------------- |
| Python                 | [`ty`](https://github.com/astral-sh/ty)                                                                  | Included with xtralab            |
| TypeScript, JavaScript | [`typescript-language-server`](https://github.com/typescript-language-server/typescript-language-server) | Registered. Install it yourself. |

## Python environments

`ty` resolves imports from a Python environment:

| Installation | Environment                                                                                                                                                                                               |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Desktop app  | The [project environment](../../desktop/#project-environments) that the kernel uses. Without a project environment, the bundled runtime.                                                                  |
| pip or uv    | The environment that was active when the server started. Otherwise, a `.venv` folder at the root of the server folder. See the [ty documentation](https://docs.astral.sh/ty/modules/#python-environment). |

## Install the TypeScript server

<Steps>

1. Install the server:

   ```bash
   npm install -g typescript-language-server typescript
   ```

2. Restart JupyterLab.

</Steps>

## Add a language server

<Steps>

1. Install the language server.

2. Run `jupyter --paths` and find a `jupyter_server_config.d/` folder in the
   `config` list.

3. Add a JSON file with the server specification to that folder. See the
   [`jupyterlab-lsp` documentation](https://jupyterlab-lsp.readthedocs.io/en/latest/Configuring.html)
   for the format.

4. Restart JupyterLab.

</Steps>
