## What you get

xtralab reshapes JupyterLab around terminal coding agents. It builds on
[ajlab](https://github.com/jtpio/ajlab), the agent-ready JupyterLab base, and
adds the pieces below on top.

<CardGrid>
  <Card title="Agent launcher" icon="rocket">
    Type an optional prompt, pick an agent, and it opens in a terminal running
    in your project. [Learn more](features/launcher/).
  </Card>
  <Card title="Rich git diffs" icon="code-branch">
    Side-by-side diffs for text and notebooks, with an editable working side so
    you can fix a line without leaving the diff. [Learn
    more](features/git-diffs/).
  </Card>
  <Card title="Ask an agent" icon="comment">
    Select code and send a prompt about it, with the file path, line range, and
    snippet attached. Queue prompts while you read. [Learn
    more](features/ask-agent/).
  </Card>
  <Card title="Omnibox" icon="magnifier">
    One search box for files, commands, and agents, with your recent picks
    remembered. [Learn more](features/omnibox/).
  </Card>
  <Card title="Terminals at a glance" icon="laptop">
    Every session badged with the agent running inside it and its latest line
    of activity. [Learn more](features/terminals/).
  </Card>
  <Card title="Agents drive the app" icon="puzzle">
    A Model Context Protocol server runs inside JupyterLab, so agents can open
    files, run cells, and read notebooks. [Learn more](agents/mcp/).
  </Card>
</CardGrid>
