The `agents` and `editors` settings control the buttons of the
[launcher](../../features/launcher/). Your entries merge with the built-in
entries by `id`, so an entry needs only the `id` and the fields that you
change.

## Change the launcher entries

<Steps>

1. Select **Settings → Settings Editor**.

2. Select **JSON Settings Editor**, then select **xtralab launcher**.

   The default value of each setting shows all built-in entries.

3. In the user preferences, add your entries to `agents` or `editors`. For
   example:

   ```jsonc
   {
     "agents": [
       { "id": "kiro", "enabled": false }, // hide an agent
       { "id": "claude", "command": "cl" }, // use a shell alias
       {
         // add an agent
         "id": "aider",
         "label": "Aider",
         "command": "aider",
         "promptArgs": []
       }
     ]
   }
   ```

4. Save the settings.

</Steps>

## Agent fields

| Field              | Type                    | Description                                                                                                                                                          |
| ------------------ | ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`               | string                  | Required. A built-in id changes that agent. A new id adds an agent.                                                                                                  |
| `label`            | string                  | The button label. The default for a new id is the id.                                                                                                                |
| `caption`          | string                  | The button tooltip and the command palette caption.                                                                                                                  |
| `command`          | string                  | The text typed in the new terminal. Shell aliases work. The default for a new id is the id.                                                                          |
| `promptArgs`       | string array, or `null` | The arguments between `command` and the quoted prompt. `[]` adds the prompt at the end. `["-i"]` adds `-i` before the prompt. `null` turns off first-prompt support. |
| `iconSvg`          | string                  | An inline SVG icon. Without it, a new agent gets a terminal icon.                                                                                                    |
| `rank`             | number                  | The position of the button.                                                                                                                                          |
| `enabled`          | boolean                 | `false` hides the agent from the launcher and the command palette.                                                                                                   |
| `requireAvailable` | boolean                 | `true` shows the button only when `command` is on the `PATH`. The default is `true`, and `false` when you change `command`.                                          |

The built-in agent ids are `claude`, `codex`, `antigravity`, `copilot`,
`goose`, `opencode`, `kiro`, `mistral-vibe`, and `pi`.

## Editor fields

The `editors` setting controls the terminal editor tile in the **Open**
section. The launcher shows the first editor, by `rank`, whose command is on
the `PATH`. The built-in editor ids are `nvim` and `vim`.

Editor entries use the same fields as agent entries, except `promptArgs`. To
remove the tile, set `enabled` to `false` for both built-in editors.
