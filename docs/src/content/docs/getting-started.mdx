This tutorial starts xtralab in a project folder, runs a coding agent, and
reviews the changes that the agent makes.

Before you start:

- [Install xtralab](../installation/).
- Install one or more [supported agents](../features/launcher/#supported-agents),
  for example Claude Code or Codex.
- Use a project folder that is a Git repository.

## Start xtralab

In a terminal, go to the project folder and start JupyterLab:

```bash
cd my-project
jupyter lab
```

JupyterLab opens in your browser. The file browser shows the project folder,
and the launcher opens in the main area.

## The workspace

| Area          | Contents                                                                                                  |
| ------------- | --------------------------------------------------------------------------------------------------------- |
| Top bar       | The menu button (☰), the sidebar toggles, and the [omnibox](../features/omnibox/) (**Search...**)        |
| Left sidebar  | [Terminals](../features/terminals/), the file browser, the Git panel, and search and replace              |
| Main area     | The [launcher](../features/launcher/), editors, notebooks, terminals, and [diffs](../features/git-diffs/) |
| Right sidebar | The **Prompt Queue** panel, after you [queue a prompt](../features/ask-agent/#queue-prompts)              |

## Start an agent

<Steps>

1. In the launcher, type a prompt in the **Start an agent** box. For example:
   `Add type hints to src/acme/metrics.py`.

2. Select an agent, for example **Claude**.

   The agent starts in a new terminal tab with your prompt.

</Steps>

## Review the changes

<Steps>

1. Go back to the **Launcher** tab. The **Changes** list shows the modified
   and untracked files in the repository.

2. Select a file. Its diff opens in a new tab.

3. To correct a line, edit it on the right side of the diff. xtralab saves the
   change to the file.

</Steps>

## Ask about a selection

<Steps>

1. Open a file and select some lines.

2. Press <kbd>Cmd/Ctrl</kbd>+<kbd>.</kbd>.

3. Type an instruction, then select the running agent as the destination.

4. Press <kbd>Enter</kbd>.

   The prompt, with the file path, the line range, and the selected code, goes
   to the agent in its terminal.

</Steps>
