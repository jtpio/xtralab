Ask an agent sends a prompt about the code that you select. The prompt
contains your instruction, the file path, the line range, and the selected
code.

## Ask about a selection

<Steps>

1. Select code in a text editor or in a notebook cell.

2. Select **Ask agent** next to the selection, or press <kbd>Cmd/Ctrl</kbd>+<kbd>.</kbd>.

3. Type an instruction.

4. Select the destination:

   - **New terminal** and an agent icon: the agent starts in a new terminal.
   - A running agent: the prompt goes to that terminal.

5. Press <kbd>Enter</kbd>, or select **Ask _agent_** (**Send to _terminal_**
   for a running agent).

</Steps>

In a [Git diff](../git-diffs/), select a line number or drag over line
numbers, then select **+** in the gutter to open the prompt box.

## Send to a running agent

The prompt box shows a button next to **New terminal** for each terminal that
runs an agent. When you select one, the prompt goes into the input of that
agent. If the agent is busy, the agent queues the prompt.

The focus stays in your editor. A notification shows with an **Open** button
that goes to the terminal.

## Queue prompts

Queue prompts to send them together, for example while you review a diff.

<Steps>

1. Open the prompt box and type an instruction.

2. Select **Queue**, or press <kbd>Cmd/Ctrl</kbd>+<kbd>Enter</kbd>.

   The first queued prompt opens the **Prompt Queue** panel in the right
   sidebar. For the next prompts, a notification shows. Select **Review** in
   the notification to open the panel.

3. In the panel, edit the instructions, change the destinations, or remove
   prompts.

4. Select **Send _N_ prompts**.

</Steps>

<Screenshot
  src={promptQueue}
  alt="The Prompt Queue panel with two queued prompts about metrics.py and the Send 2 prompts button"
/>

Prompts for the same destination go in one numbered message. The queue stays
when you reload the page. To remove all prompts, select **Clear**.

## Keyboard shortcuts in the prompt box

| Shortcut                             | Action                      |
| ------------------------------------ | --------------------------- |
| <kbd>Enter</kbd>                     | Send the prompt             |
| <kbd>Shift</kbd>+<kbd>Enter</kbd>    | Start a new line            |
| <kbd>Cmd/Ctrl</kbd>+<kbd>Enter</kbd> | Add the prompt to the queue |
| <kbd>Esc</kbd>                       | Close the prompt box        |
