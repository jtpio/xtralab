## Terminal rows

Each row shows:

- The terminal title.
- The icon of the agent or editor that runs in the terminal. xtralab finds it
  from the processes of the terminal, also for agents that you start
  yourself.
- The latest line of output of the agent.

Terminal tabs in the main area show the same icon.

| Button                          | Location      | Action                                                      |
| ------------------------------- | ------------- | ----------------------------------------------------------- |
| **+** (New Terminal)            | Panel toolbar | Opens a menu: start an installed agent, or open a terminal. |
| **■** (Shut Down All Terminals) | Panel toolbar | Stops all terminals, after you confirm.                     |
| **×** (Shut down)               | Row           | Stops that terminal.                                        |

### Settings

**Settings → Settings Editor → xtralab Terminals panel**

| Setting                                                       | Default | Description                                           |
| ------------------------------------------------------------- | ------- | ----------------------------------------------------- |
| Show agent activity under each terminal (`showAgentActivity`) | `true`  | Shows the latest line of output under each agent row. |

## Move sections between panels

These sidebar sections are movable:

| Section   | Panel                                                                                            |
| --------- | ------------------------------------------------------------------------------------------------ |
| Terminals | Terminals                                                                                        |
| File tree | File browser. The toolbar above the tree moves with it.                                          |
| Kernels   | Running Terminals and Kernels (hidden by default, see [Sidebar tabs](../defaults/#sidebar-tabs)) |

<Steps>

1. Right-click the section header. For the file tree, right-click its
   toolbar.

2. Select **Move to _panel_**, for example **Move to Terminals**.

</Steps>

In the new panel, you can drag the section header to change the order, and
select it to collapse the section. To move the section back, right-click it
and select the original panel. JupyterLab restores the arrangement when you
reload the page.

### Custom Panel

Each move menu has **Move to Custom Panel**. The Custom Panel is an empty
sidebar panel for the sections that you move into it. Its tab shows only when
it contains a section.

The file browser tab also hides when its tree is in another panel. It shows
again when the tree comes back.

## Notifications

xtralab shows a notification when a program in a terminal sends one of these
signals:

| Signal  | Description                                                                   |
| ------- | ----------------------------------------------------------------------------- |
| OSC 9   | The iTerm2 notification sequence                                              |
| OSC 777 | The Ghostty and rxvt notification sequence                                    |
| Bell    | The terminal bell. Controlled by the **Notify on the terminal bell** setting. |

Coding agents send these signals when they finish a task or need input. The
desktop app sets `TERM_PROGRAM=iTerm.app` in its terminals. With this value,
most agents send OSC 9 by default.

The notification does not show when you look at that terminal. The desktop
app shows native notifications. In a browser, xtralab uses web notifications,
and the browser asks for permission first. If notifications do not show in
the desktop app on macOS, see
[Troubleshooting](../../desktop/#notifications-do-not-appear-on-macos).

### Settings

**Settings → Settings Editor → xtralab terminal notifications**

| Setting                                      | Default | Description                                 |
| -------------------------------------------- | ------- | ------------------------------------------- |
| Enable terminal notifications (`enabled`)    | `true`  | Shows notifications from terminal programs. |
| Notify on the terminal bell (`notifyOnBell`) | `true`  | Also shows a notification for a plain bell. |
