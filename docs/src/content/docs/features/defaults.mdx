title: Defaults and themes
description: A quieter workspace out of the box.
---

xtralab applies a set of quieter, opinionated defaults so the workspace stays
calm without any configuration.

## Quieter defaults

Unused UI is hidden for a calmer workspace, and the activity bar sits at the
top. Autocompletion, continuous LSP hinting, code folding, and
gitignore-aware quick open are on by default. See the
[bundled labconfig overrides](https://github.com/jtpio/xtralab/blob/main/jupyter-config/labconfig)
for the full set.

## Themes

xtralab ships light and dark themes (Pierre, Cursor, Day, Night) but picks
none for you: JupyterLab's default light theme stays active until you choose
one under **Settings → Theme**.

## Everything stays configurable

These are defaults, not decisions made for you. Anything xtralab overrides can
be changed back from the Settings Editor, and per-user settings always win
over the shipped defaults.
