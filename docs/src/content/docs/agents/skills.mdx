xtralab includes four [Agent Skills](https://agentskills.io). They are in the
[`agent-skill/`](https://github.com/jtpio/xtralab/tree/main/agent-skill)
folder of the repository.

| Skill                     | Use it to                                                                                                                                                       | Example request                                  |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| `open`                    | Start xtralab in a folder from a terminal session and open it in the browser. The agent runs xtralab with `uvx`, so nothing is installed into the project.      | "Open xtralab in this worktree."                 |
| `stop`                    | Stop the xtralab server of a folder, or all of them, or list the running ones. The agent finds servers by folder, so no port is needed.                         | "Stop xtralab for this worktree."                |
| `customize-jupyterlab`    | Change JupyterLab and xtralab settings. The agent edits the correct configuration file.                                                                         | "Hide the status bar by default."                |
| `guided-code-walkthrough` | Get a tour of code in the running app. The agent opens files, highlights lines, and builds a walkthrough panel with text, code, and diagrams beside the editor. | "Walk me through how this module fits together." |

In Claude Code, the skills are also slash commands: `/xtralab:open path/to/folder`
runs [`uvx xtralab open`](../../installation/#run-without-installing) for that
folder and reports its URL. The server runs after the agent session ends.
`/xtralab:stop path/to/folder` stops it.

The `guided-code-walkthrough` skill uses the MCP server: see
[Connect agents with MCP](../mcp/).

## Install the skills

The skills use the Agent Skills format. They work with Claude Code, Codex
CLI, Gemini CLI, GitHub Copilot, and other agents that read this format.

<Tabs syncKey="agent">
  <TabItem label="Claude Code">
    The repository is also a plugin marketplace. The xtralab plugin installs
    the skills and registers the MCP server:

    ```bash
    claude plugin marketplace add jtpio/xtralab
    claude plugin install xtralab@xtralab
    ```

  </TabItem>
  <TabItem label="Other agents">
    Copy the skills into the shared skills folder:

    ```bash
    git clone --depth=1 https://github.com/jtpio/xtralab.git /tmp/xtralab
    mkdir -p ~/.agents/skills
    cp -r /tmp/xtralab/agent-skill/skills/* ~/.agents/skills/
    ```

  </TabItem>
</Tabs>

See
[`agent-skill/README.md`](https://github.com/jtpio/xtralab/blob/main/agent-skill/README.md)
for the folders that each agent reads and for other installation methods.
