The xtralab desktop app is a standalone application for macOS (DMG) and Linux
(AppImage). It includes its own Python runtime, so it does not need Python,
`pip`, `uv`, or network access.

## Open a project

<Steps>

1. Start the app. The launcher window opens.

2. Select **Open folder...**, or select a folder in **Recent folders**.

3. In **Python environment**, select the environment for notebook kernels. To
   use an interpreter that is not in the list, select
   **Choose interpreter...**.

4. Select **Open in xtralab**.

</Steps>

Each project has its own JupyterLab server, window, and workspace. The open
tabs and the panel layout are saved for each project.

## Project environments

The launcher finds these Python environments in the project folder:

| Folder                 | Environment type    |
| ---------------------- | ------------------- |
| `.venv`, `venv`, `env` | Virtual environment |
| `.conda`               | Conda environment   |
| `.pixi/envs/<name>`    | Pixi environment    |

When you select an environment, xtralab registers a kernel for the project
that uses its interpreter. The JupyterLab server continues to run from the
bundled runtime. An environment is available as a kernel only when `ipykernel`
is installed in it.

The bundled `ty` language server uses the same environment. See
[Language servers](../customize/language-servers/).

## Tabs and windows on macOS

Project windows follow the macOS setting **Prefer tabs when opening
documents** (**System Settings → Desktop & Dock**):

| Setting value | Project windows open as                                                   |
| ------------- | ------------------------------------------------------------------------- |
| Always        | Tabs in one window                                                        |
| Other values  | Separate windows. To combine them, select **Window → Merge All Windows**. |

To open the launcher in a new tab, press <kbd>Cmd</kbd>+<kbd>T</kbd> or select
**+** in the tab bar. The project that you open replaces the launcher tab.

## Session restore

When you quit the app, it saves the open projects. When you start it again, it
reopens them:

- The windows and tabs go back to their positions, and the last active project
  is selected.
- Each window restores its open files and panel layout.
- The launcher shows the progress while the servers start.

<Screenshot
  src={restore}
  alt="The launcher window restoring three projects: one is open, two are starting"
/>

Windows that you close before you quit do not reopen. Tab groups that you
make with the window manager (for example with **Merge All Windows**) reopen
as separate windows.

## Updates

| Platform | Update method                                                                                                                                                                                                   |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| macOS    | The app checks for releases in the background and asks before it downloads one. When the download is complete, select **Restart to update**. To check now, select **Check for updates** in the launcher window. |
| Linux    | No automatic updates. Download the new AppImage from the [releases page](https://github.com/jtpio/xtralab/releases).                                                                                            |

The launcher window shows the app version in its bottom corner.

## Troubleshooting

### Notifications do not appear on macOS

The app shows native notifications for [terminal
notifications](../features/terminals/#notifications). macOS asks for
permission the first time a notification fires.

<Steps>

1. Open **System Settings → Notifications** and select **xtralab**.

2. Make sure that **Allow notifications** is on. The app can be in this list
   with notifications off, even if macOS did not ask for permission.

3. If **xtralab** is not in the list, refresh the registration of the app
   bundle:

   ```sh
   /System/Library/Frameworks/CoreServices.framework/Frameworks/LaunchServices.framework/Support/lsregister -f /Applications/xtralab.app
   ```

4. Quit and start the app again.

</Steps>
