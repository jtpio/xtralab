xtralab is on [PyPI](https://pypi.org/project/xtralab/). It requires Python
3.11 or newer. The [desktop app](../desktop/) includes its own Python runtime
and does not need either of the methods on this page.

## Install with pip

```bash
pip install xtralab
xtralab
```

The `xtralab` command starts JupyterLab with the
[settings folder of xtralab](#settings-folder). `jupyter lab` also works, with
the default Jupyter settings folder.

## Install with uv

| Method                                  | Use it to                                               |
| --------------------------------------- | ------------------------------------------------------- |
| [`uvx`](#run-without-installing)        | Run xtralab in any folder, without installing it.   |
| [`uv tool install`](#install-as-a-tool) | Make the `xtralab` command available in all shells. |
| [`uv add`](#add-to-a-project)           | Add xtralab to the dependencies of a project.       |

### Run without installing

```bash
uvx xtralab
```

uv creates a cached environment for xtralab on the first run and uses it again
on the next runs. xtralab starts in the current folder.

To start a server for a folder in the background, for example from a coding
agent, use `open`:

```bash
uvx xtralab open path/to/folder
```

The command prints the URL of the server, reuses a server that already serves
the folder, and returns. The server opens a browser tab and continues to run
after the terminal closes. `uvx xtralab stop path/to/folder` stops it,
`uvx xtralab list` shows the running xtralab servers, and
`uvx xtralab stop --all` stops all of them. The
[agent skills](../agents/skills/) use these commands.

### Install as a tool

```bash
uv tool install xtralab
```

### Add to a project

```bash
uv add xtralab
uv run xtralab
```

## Verify the installation

<Steps>

1. Start JupyterLab.

2. Select the menu button (☰) at the left of the top bar, then
   **Help → About xtralab**.

   The dialog shows the xtralab version and the JupyterLab version.

</Steps>

## Upgrade

| Installed with    | Command                             |
| ----------------- | ----------------------------------- |
| `pip`             | `pip install --upgrade xtralab`     |
| `uvx`             | `uvx xtralab@latest`                |
| `uv tool install` | `uv tool upgrade xtralab`           |
| `uv add`          | `uv sync --upgrade-package xtralab` |

## Settings folder

The `xtralab` command stores the JupyterLab settings, the workspaces, and the
Jupyter server configuration in the folder of xtralab, the same folder as the
[desktop app](../desktop/). It does not read `~/.jupyter`. Kernels and other
Jupyter data stay in the default Jupyter folders.

| System  | Folder                                                 |
| ------- | ------------------------------------------------------ |
| macOS   | `~/Library/Application Support/xtralab/jupyter/config` |
| Linux   | `~/.config/xtralab/jupyter/config`                     |
| Windows | `%APPDATA%\xtralab\jupyter\config`                      |

`xtralab paths` prints the settings folder. To use a different folder, set the
`JUPYTER_CONFIG_DIR` environment variable before you start xtralab.

## Included packages

xtralab is a meta-package. It installs these packages and adds its own
JupyterLab extension. See
[`pyproject.toml`](https://github.com/jtpio/xtralab/blob/main/pyproject.toml)
for the versions.

| Package                                             | Provides                                              |
| --------------------------------------------------- | ----------------------------------------------------- |
| [`ajlab`](https://github.com/jtpio/ajlab)           | The agent-ready JupyterLab base                       |
| `jupyterlab`                                        | JupyterLab 4.6 or newer                               |
| `jupyterlab-git`                                    | The Git panel and Git commands                        |
| `jupyterlab-lsp`, `ty`                              | Language server support and a Python language server  |
| `jupyterlab-quickopen`                              | The file index of the [omnibox](../features/omnibox/) |
| `jupyterlab-search-replace`                         | Search and replace in all files of the project        |
| `jupyterlab-vim`                                    | Vim key bindings, disabled by default                 |
| `jupyter-server-mcp`, `jupyterlab-commands-toolkit` | The [MCP server](../agents/mcp/) and its tools        |
| Pierre, Cursor, Day, and Night themes               | Light and dark [themes](../features/defaults/#themes) |
